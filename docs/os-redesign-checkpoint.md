# DulajOS redesign checkpoint

The requested direction replaces the initial dark/green editorial portfolio with a modern desktop OS experience.

## Direction

- Cobalt and ice-blue abstract wallpaper; silver/white glass panels.
- A compact menu bar, desktop application shortcuts and an animated app dock.
- Functional windows that open, focus, close, minimise, maximise and drag.
- A keyboard quick switcher available with Ctrl/Cmd K.
- A single-window app layout on mobile, with a persistent bottom dock.
- Reduced-motion support and keyboard alternatives for dragging.

## Portfolio apps

1. About: overview, capabilities, education and featured projects.
2. Projects: searchable categories, ten project records and detailed contributions.
3. Experience: the resume-confirmed employment history.
4. Resume: the original PDF with view and download actions.
5. Contact: email, LinkedIn, GitHub and a validated email-draft form.
6. GitHub: verified profile `dulajpasqual` and the portfolio source repository.

All existing project descriptions and the original resume are retained. Client project illustrations remain labelled as project identities rather than fabricated screenshots. Enquiry drafts open an email application; no backend submission is claimed.

## Progress and validation

The OS app components, desktop shell and window manager were drafted in the Sites checkout. The editing environment disconnected while the stylesheet, wallpaper integration and checks were being completed. The live Site has not been replaced.

This branch is a recovery checkpoint. It currently contains the core window manager and this direction document; it is not a completed or validated portfolio implementation.
